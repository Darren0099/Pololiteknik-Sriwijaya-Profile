# Politeknik Negeri Sriwijaya — Campus Profile Website Concept

Proyek latihan desain **website profil kampus Politeknik Negeri Sriwijaya (POLSRI)** untuk menyajikan pengenalan institusi, bidang akademik, fasilitas, dan informasi lingkungan kampus.

## Tujuan

Menyusun konten profil perguruan tinggi menjadi halaman yang terstruktur agar pembaca mudah menjelajahi informasi jurusan, kegiatan, dan fasilitas dari satu antarmuka.

## Halaman dan bagian yang dibuat

- `index.html`: profil institusi, hero, informasi akademik dan sorotan kampus.
- `Polsri akademik.html`: konten akademik.
- `Why Polsri.html`: alasan mengenal kampus dan pengalaman belajar.
- `Contact_page.html`: kontak dan informasi institusi.
- `See More_page.html`: konten lanjutan.
- CSS terpisah dan JavaScript untuk navigasi serta interaksi halaman.

## Teknologi

**HTML5, CSS3, JavaScript**, dengan aset visual kampus dan penggunaan beberapa stylesheet.

## Hasil dan batasan

Website profil kampus berbasis frontend statis sebagai eksplorasi desain web institusi. Ini merupakan **proyek portofolio pribadi**, bukan kanal resmi atau pengganti website POLSRI. Sebagian navigasi pada sumber masih merujuk nama halaman yang berbeda dan mungkin membutuhkan perbaikan sebelum dijadikan situs yang siap digunakan publik.
